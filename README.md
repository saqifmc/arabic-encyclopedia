# Arabic Encyclopedia — Version 4

The content is split into four independent JSON files:

- `vocab.json` — general vocabulary
- `verbs.json` — verbs and Ṣarf information
- `speaking.json` — practical speaking phrases
- `nahw.json` — Naḥw / grammar concepts
